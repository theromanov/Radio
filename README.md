# Online Radio — Landing Page

A landing page for an online radio training intensive, built with HTML and CSS.

## About the Project

This project promotes a free two-day intensive about creating and developing an online radio station. It introduces the training program, highlights its benefits, and encourages visitors to register.

## Features

- Promotional hero section with a call-to-action button
- Training program overview
- Introduction to online radio
- Benefits and learning outcomes
- Bonus and gift section
- Webinar information
- Footer with support and contact links

## Built With

- HTML5
- CSS3
- Google Fonts (Roboto)

## Getting Started

1. Clone this repository.
2. Open `src/index.html` in your browser.

No additional dependencies are required.
